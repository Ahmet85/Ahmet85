# Gaziantepli Gıda – Kurumsal Web Sitesi

Gaziantepli Gıda Paz. San. Tic. Ltd. Şti. için tek sayfalık, Türkçe tanıtım sitesi.
Herhangi bir kurulum gerektirmez; `index.html` dosyasını tarayıcıda açmanız yeterlidir.

## Dosyalar

- `index.html` – sayfa içeriği
- `assets/css/style.css` – tasarım (renkler logodan alınmıştır)
- `assets/js/main.js` – mobil menü
- `assets/img/` – logo ve site simgeleri

## Doldurulacak bilgiler

Sayfada sarı-kahverengi italik görünen `[...]` alanları yer tutucudur:

- Çalışma saatleri
- Çalışılan marka isimleri

## Yayına alma

GitHub Pages: depo ayarlarında **Settings → Pages → Branch** kısmından bu dalı seçin.
